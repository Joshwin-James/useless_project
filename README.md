# Spud-tacular Site Design

Create a playful website UI inspired by the reference image, but make it potato-themed. Use a cute retro/webcore aesthetic with bright colors, hand-drawn elements, chunky typography, stickers, doodles, and slightly imperfect scrapbook-style sections. The hero should feature a large cute potato centered on the page, with expressive eyes that subtly follow the user’s cursor. Keep the potato as the main visual focus. Build the rest of the page with fun potato-themed sections, cards, buttons, illustrations, and playful scrolling interactions while keeping the layout clean, quirky, and visually cohesive.
